# 🚀 Desafios de JavaScript (Básico → Avançado)

Este conjunto de desafios foi criado para consolidar todo o aprendizado de JavaScript básico, evoluindo até problemas mais completos e próximos da prática real.

## 📚 Como usar

1. Resolva os desafios na ordem (eles evoluem em dificuldade).
2. Sempre tente fazer sozinho primeiro.
3. Comente seu código explicando o raciocínio.
4. Refatore depois (melhore nomes e organização).
5. Se travar, divida o problema em partes menores.

---

## 🧠 1. Ficha de apresentação

### Objetivo:
Treinar variáveis, tipos e saída de dados.

### Requisitos:
- Criar variáveis: nome, idade, cidade e se está estudando.
- Exibir tudo no console.
- Mostrar o tipo de cada variável.

### Exemplo:
```js
Nome: Leonel
Idade: 18
Cidade: Nova Russas
Estudando: true
Tipo: string, number, boolean
```

## 🔄 2. Conversor de valores
Objetivo:
Treinar conversão e coerção.

Requisitos:
Converter "10" para número.

Somar 5 e multiplicar por 2.

Mostrar resultado.

Mostrar "10" + 5.

Extra:
Explique no comentário por que os resultados são diferentes.

## 📊 3. Calculadora de notas
Objetivo:
Condicionais e operadores.

Requisitos:
Receber 3 notas.

Calcular média.

Classificar:

≥ 7 → Aprovado

5–6.9 → Recuperação

< 5 → Reprovado

Extra:
Fazer com operador ternário.

## 🔢 4. Par ou ímpar + positivo/negativo
Objetivo:
Operadores e lógica.

Requisitos:
Verificar se número é par ou ímpar.

Verificar se é positivo, negativo ou zero.

## 💰 5. Sistema de desconto
Objetivo:
Lógica com múltiplas condições.

Regras:
≥ 200 → 20% desconto

100–199 → 10%

< 100 → sem desconto

Mostrar:
valor original

desconto

valor final

Extra:
Criar versão com switch para tipo de cliente.

## 🔁 6. Tabuada
Objetivo:
Laço for.

Requisitos:
Mostrar tabuada de 1 a 10.

Extra:
Validar número entre 1 e 10.

## 🔄 7. Contador inteligente
Objetivo:
for, while, incremento e decremento.

Requisitos:
Contar de início até fim.

Se início > fim → contagem regressiva.

## 🧮 8. Biblioteca matemática
Objetivo:
Funções + Math.

Criar funções para:
Área de retângulo

Raiz quadrada

Arredondar para cima

Arredondar para baixo

Número aleatório

Extra:
Função de IMC.

## 📋 9. Menu com switch
Objetivo:
switch e organização.

Menu:
Consultar saldo

Sacar

Depositar

Sair

Extra:
Tratar opção inválida.

## 🏗️ 10. Sistema de alunos (DESAFIO FINAL)
Objetivo:
Misturar tudo aprendido.

Cada aluno deve ter:
nome

idade

nota

status

Sistema deve:
cadastrar alunos

listar todos

listar aprovados

média da turma

maior nota

Extra:
usar try/catch

usar callback
