## ⚡ Quick Start em 5 Minutos

### 1. **Teste um Exemplo**
```javascript
// Abra o console (F12) em qualquer página e cole:

const el = document.querySelector("h1");
el.textContent = "Mudei o título!";
el.style.color = "red";
el.classList.add("destaque");

// Você vai ver que funcionou!
```

### 2. **Abra exercicios.html**
- Arquivo: `exercicios.html`
- Clique em um botão (ex: "Testar Ex. 1")
- Veja o resultado na página

### 3. **Leia Um Arquivo Pequeno**
- Abra: `06-Eventos-Básico.js`
- Leia os comentários
- Teste o código no seu navegador
